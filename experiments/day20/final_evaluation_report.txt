RESEARCH FINDINGS
------------------------------------------------------------
1. Within-capture known-attack evaluation produced high classification performance.
2. Source-separated experiments exposed poor generalization to some unseen attacks.
3. Day 16 showed many missed DDoS attacks received very low ATTACK scores.
4. Increasing XGBoost complexity provided negligible within-capture improvement.
5. The reported evaluations do not establish live-network or production performance.

LIMITATIONS
------------------------------------------------------------
1. Experiments used different training data and model configurations.
2. Within-capture splits may contain related flows.
3. Source-file separation does not guarantee independent network sessions.
4. Some configurations were selected using the reported validation datasets.
5. The project has not been evaluated on independent live network traffic.

CONCLUSION
------------------------------------------------------------
High within-capture performance did not guarantee
strong recognition of attack categories excluded
from training. Additional independent evaluation
is required before production claims can be made.
